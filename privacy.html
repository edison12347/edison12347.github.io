calsync privacy policy

Last updated: 2 November 2026

calsync is a personal tool used only by its author to sync his own calendars. It is not offered to anyone else.

What it accesses

With the user's consent, calsync reads and writes the user's Google Calendar events (Google Calendar API, scope calendar) and the user's Microsoft Outlook calendar.

How the data is used

  • Event times and titles are used only to keep the user's own two calendars in sync.
  • The data is processed on the user's own computer. calsync has no server, and nothing is sent to any third party or used for advertising, analytics or model training.
  • Sign-in tokens are stored in the operating system's keychain on that computer.

Google user data

calsync's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be withdrawn at any time at myaccount.google.com/connections.
